# Лемалар · Тьюторы — платформа для воскресных уроков

Мобильное приложение (PWA) для группы из ~20 тьюторов: карточки «как в Quizlet», но с **обязательным объяснением**
к каждому слову, тесты в конце урока, домашние задания, обсуждения, дневник размышлений, баллы и рейтинг,
панель учителя со статистикой.

**Всё бесплатно и целиком в вашем Google-аккаунте:**
- сайт — на **GitHub Pages**;
- база данных — **Google Таблица** (вы видите все данные сами, можно делать диаграммы);
- сервер — **Google Apps Script** (бесплатный, привязан к таблице);
- презентации — на вашем **Google Диске**.

Платных сервисов нет. Пока в `config.js` пусто, приложение работает в **ДЕМО-режиме** (данные только в браузере).

```
index.html, js/, style.css …   ← сайт (GitHub Pages)
google/Code.gs                 ← сервер (вставляется в Apps Script)
google/appsscript.json         ← настройки Apps Script
```

## Установка (≈ 15 минут)

### 1. Google Таблица и сервер
1. Откройте **sheets.new** → назовите таблицу, например «Лемалар — база».
2. **Расширения → Apps Script**. Удалите код по умолчанию и вставьте весь файл `google/Code.gs`.
3. В самом верху впишите **своё настоящее имя и фамилию** (`TEACHER_FIRST`, `TEACHER_LAST`).
4. Слева **⚙ Настройки проекта** → включите «Показывать файл манифеста appsscript.json», вернитесь в «Редактор»,
   откройте `appsscript.json` и вставьте содержимое `google/appsscript.json` (часовой пояс Алматы и доступ для веб-приложения).
5. Сверху выберите функцию **`setup`** → **Выполнить**. Google попросит разрешения — это ваш собственный скрипт:
   «Проверить разрешения» → ваш аккаунт → «Дополнительно» → «Перейти на страницу … (небезопасно)» → «Разрешить».
   После запуска в журнале появится **код учителя** (он же в листе `profiles`). Запишите его.
6. **Начать развертывание → Новое развертывание → ⚙ Веб-приложение**:
   «Выполнять от имени: **Меня**», «У кого есть доступ: **Все**» → Развернуть. Скопируйте **URL веб-приложения** (оканчивается на `/exec`).
   Откройте его в браузере — должна появиться надпись «Лемалар API работает».

> «Доступ: Все» нужен, чтобы телефоны учеников могли обратиться к серверу. Данные от этого не открываются:
> без входа по коду и паролю сервер ничего не отдаёт.

### 2. Настройка сайта
В `config.js` вставьте адрес:
```js
API_URL: "https://script.google.com/macros/s/…/exec",
```

### 3. GitHub Pages
Загрузите все файлы в репозиторий → **Settings → Pages → Deploy from a branch → main / (root)**.
Сайт откроется по адресу `https://ВАШ-НИК.github.io/ИМЯ-РЕПОЗИТОРИЯ/`.

### 4. Первый вход
1. Сайт → **Регистрация** → код учителя из шага 5 → придумайте пароль. **Зарегистрируйтесь первым**, пока код никто не знает.
2. **Панель → Группа**: вставьте 20 участников списком (`Имя Фамилия, Команда`) — получите личные коды, разошлите в чат.
3. Ученики: сайт → **Регистрация** → код → пароль. **Имя и фамилия берутся из вашего списка и не редактируются.**
4. На телефоне: iPhone (Safari) — «Поделиться» → «На экран Домой»; Android (Chrome) — меню ⋮ → «Установить приложение».

## Как проходит воскресенье
| Время | Что делает учитель | Где |
|---|---|---|
| До урока | Создаёт урок, загружает презентацию (файл на Диск или ссылка), карточки (по одной или таблицей), тему обсуждения, ДЗ | Панель → Уроки / Карточки |
| Начало | Публикует урок, отмечает посещаемость | Уроки («Опубликован»), Посещаемость |
| Конец | Включает **«Тест открыт»** — ученики пишут тест с таймером | Уроки |
| После | «Обсуждение открыто»; вечером — **«Закрыть неделю»** (бонус топ-3: 15/10/5) | Уроки, Баллы |
| Неделя | «Обзор»: кто не заходил, трудные слова, ДЗ и дневники | Панель → Обзор |

Каждый день ученик: отмечает «прочитал(а) сегодня» (серия 🔥), проходит «Повторение дня» (~5 минут), по желанию пишет строку в дневник.

## Уровень турецкого и наставничество
Учитель задаёт каждому **уровень турецкого** при добавлении в группу (`Имя Фамилия, Команда, начинающий`) или потом в таблице «Группа».
Уровень меняет множитель баллов **за учёбу** (выученные слова, тренировка, тесты); остальное (ДЗ, дневник, посещение, отметка чтения) — без множителя.

| Уровень | Множитель |
|---|---|
| Начинающий | ×2 |
| Средний (по умолчанию) | ×1,5 |
| Продвинутый | ×1 |

**Наставничество:** назначьте продвинутому ученику подопечного с более низким уровнем (в «Группе» в списке наставников показаны только те, чей уровень выше).
Когда подопечный набирает баллы за учёбу, наставник **автоматически получает +25%** от них (не больше 10 баллов в день за каждого подопечного),
а вы можете добавить бонус вручную («Баллы» → «Помощь товарищу»). Множители и доля настраиваются в начале `google/Code.gs` (`LEVELS`, `MENTOR_SHARE`, `MENTOR_DAILY_CAP`) и дублируются в `js/data.js` (`LEVEL_INFO`, только для подписей).

## Как начисляются баллы
Базовые значения (до множителя уровня):
| За что | Баллы | Ограничение |
|---|---|---|
| Слово стало «выученным» (2 верных ответа в разные дни) | +5 | один раз на слово |
| Верный ответ в тренировке (выбор, письмо, пары) | +1 | до 40 в день |
| Тест урока | +2 за верный ответ | засчитывается лучшая попытка |
| ДЗ сдано вовремя | +10 | один раз |
| Отметка «читал(а) сегодня» | 3…10 (растёт с серией) | раз в день |
| Запись в дневнике | +2 | раз в день |
| Посещение урока | +10 | отмечает учитель |
| Одобренная карточка/вопрос ученика | +5 | при одобрении |
| Топ-3 недели | 15 / 10 / 5 | кнопка «Закрыть неделю» |
| Наставничество, лучший вопрос, поощрение | любое | вручную, Баллы |

Лимиты и «один раз» проверяются **на сервере** (дневной лимит тренировки тоже умножается на уровень). Правила меняются в `google/Code.gs` (функция `award_`) и в `js/data.js` (`INTERVALS`, `LEARNED_BOX`, `NEW_PER_DAY`).

## Что внутри
- **Карточки с объяснением:** поле «Объяснение» обязательно и в интерфейсе, и на сервере. Режимы: карточки, выбор, письмо, пары, «умная тренировка». После каждого ответа показываются объяснение, пример и источник. Интервальное повторение: 1 → 3 → 7 → 14 → 30 дней.
- **Тест:** вопросы из карточек + одобренные вопросы учеников, таймер, число попыток, разбор с объяснением. Сервер не даёт отправить результат при закрытом тесте или после исчерпания попыток.
- **Дневник, наставничество, вопросы и карточки от учеников с модерацией, команды** (рейтинг — среднее на человека).
- **Сброс пароля из панели** (🔑 в «Группе»): прогресс сохраняется, ученик регистрируется заново по тому же коду.
- **Лист «Сводка»** в Google Таблице: меню **Лемалар → Обновить лист «Сводка»** — готовая таблица по ученикам для печати и диаграмм.

## Важно знать
- **Изменили `Code.gs`?** Нужно заново опубликовать: **Начать развертывание → Управление развертываниями → ✏ → Версия: «Новая версия» → Развернуть**. Адрес `/exec` при этом не меняется. Без этого сайт продолжит работать со старой версией сервера.
- **Таблицу можно смотреть, но не правьте листы вручную** (не сортируйте, не вставляйте строки, не трогайте `profiles`, где хранятся хэши паролей): данные могут разойтись. Резервная копия: **Файл → Создать копию**.
- **Скорость:** каждый запрос к Apps Script занимает ~1–2 секунды (это нормально для Google). Сайт объединяет одновременные запросы, а ответы в тренировке отправляются в фоне.
- **Лимиты бесплатного Google-аккаунта** (одновременные запросы, время выполнения в сутки) для 20 человек с большим запасом.
- **Презентации** сохраняются в папку «Лемалар — презентации» на вашем Диске и открываются по ссылке всем, у кого она есть. Если администратор Google Workspace запретил публичные ссылки, загрузите файл на Диск вручную и вставьте ссылку в урок.
- **Честность баллов.** Ответы на вопросы проверяются в браузере ученика, поэтому технически подкрутить результат можно. Сервер ограничивает суммы и частоту (см. таблицу), но это учебный инструмент, а не экзаменационная система: рассчитан на доверие внутри группы.
- **Дневники видны ученику и учителю** (об этом написано на экране дневника).
- **Обновление сайта:** после замены файлов на GitHub измените `CACHE = "lemalar-v3"` в `sw.js` на `v3`, иначе телефоны могут показывать старую версию до второго открытия.
- Локальный запуск для проверки: `python3 -m http.server 8000` → http://localhost:8000 (в демо-режиме).
